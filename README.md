# Face Scanner App

Professional 3D face/head scanner for Android (optimized for Samsung Galaxy S23 Ultra).
Outputs high-quality STL files for 3D printing and modeling.

## Features (Planned)
- Real-time face detection and guided scanning
- Full head scanning with multi-angle capture
- External teeth / smile / bite scanning mode
- Interactive 3D preview (Three.js)
- STL export
- Modular, professional architecture for easy upgrades

## Tech Stack
- **Flutter** (main app framework)
- **ARCore** (face detection & tracking)
- **Three.js** (3D mesh processing & preview)
- Clean modular architecture

## Development Principles
- Small, careful patches
- Permission before every significant push
- Minimal builds and costs
- Professional, maintainable code

# Web Version (PWA)

نسخه وب برای تست مستقیم روی گوشی.

## چطور تست کنی
1. روی گوشی Chrome را باز کن
2. به آدرس زیر برو:
   https://mokhtarazizpour-gif.github.io/face-scanner-app/web/

(بعد از فعال کردن GitHub Pages)

## قابلیت‌های فعلی
- دسترسی به دوربین جلو
- راهنمای دایره‌ای برای قرار دادن صورت
- آماده برای اضافه کردن Three.js و MediaPipe

## مراحل بعدی
- تشخیص صورت با MediaPipe
- ساخت مش سه‌بعدی
- پیش‌نمایش مدل
- خروجی STL
